# Local Messenger

Local Messenger is a TypeScript-based peer-to-peer messaging and file-sharing application that enables secure communication between devices on the same local network. The application works without relying on external servers or cloud services, ensuring privacy, speed, and reliability. Users can exchange messages in real time, automatically discover nearby devices, and transfer files up to 10 GB at high LAN speeds, making it ideal for offices, classrooms, homes, and offline collaboration environments.

## Features

- Real-time local network messaging
- Automatic device discovery
- Secure peer-to-peer communication
- File sharing up to 10 GB
- High-speed LAN transfers
- No cloud storage required
- No external server dependency
- Lightweight and easy to use
- Built with TypeScript
- Cross-platform compatibility

## Prerequisites

Before getting started, make sure you have the following installed:

- Node.js (v18 or higher)
- npm or yarn

## Installation

### Clone the Repository

```bash
git clone https://github.com/arav144/local-Messenger.git
cd local-Messenger
```

### Install Dependencies

```bash
npm install
```

## Running the Application

### Development Mode

```bash
npm run dev
```

### Production Build

```bash
npm run build
npm start
```

## Usage

1. Launch the application on devices connected to the same local network.
2. Nearby devices will be discovered automatically.
3. Select a device to start chatting.
4. Send and receive messages instantly.
5. Share files directly between devices.
6. Transfer files up to 10 GB without using cloud storage.
